supercompress · 会话记忆机制

两层不混：压缩层决定「什么进窗口」，记忆层决定「关掉重开还在」。全图仅 2 个数字（断电上界 / 决策 band）· 3 条硬不变量 · 无监控层 / stamp 三态 / 307 守卫。

压缩层 · 无状态

  • 入窗即 tiering：P0 永不压 / P1 压不丢 / P2 先丢
  • P0 write-before-compress：即写即 fsync+读回，过了才发锚点
  • 不变量①未 fsync 永不发锚 → 崩溃死指针恒 0
  • 不变量②digest 未就绪时 P0 不可驱逐

记忆层 · 单一事实源

  • jsonl append-only · content_hash（NFC）幂等去重
  • 召回格：BM25 + P0 boost + O(1)，确定性已证（不带百分比）
  • 决策格：~80–93% band（中位数 93% = 参考带中心）
  • 单向 digest+锚点 → replay / materialize，不画回路

诚实口径 · 全图仅 2 个数字

  • 断电 ≤256 KB + 1 条 in-flight（默认可配），P0 零丢失
  • 决策 ~80–93% band，不写「可复现 93%」单点
  • 真扛审稳定数 = 单发 n≥50（v1 follow-up，非门）
  • 禁画监控管线 / stamp 三态 / 307 守卫
