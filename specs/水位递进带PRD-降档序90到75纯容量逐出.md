## 1. 降档水位递进带（A 面主体）

### 1.1 执行序（降档，非升档——owner 纠正）

compact 触发（sc 侧 55% 预检）后，**从最高危险度档先试、逐档降**，每档"压到目标水位下就停、压不到（估值回收不足）pass 给下一档"：

```
used_tokens > 0.9×cap  → ① 90% 超压档（tier90，纯容量）：P0 段逐出折存根（绕 digest 闸 + 放开 user 指令 structural P0；goal/ledger 尾永不逐）
                          压到 0.9×cap 下 → 停；压不到 → pass 给 ②
used_tokens > 0.75×cap → ② 75% 软水线（tier75，P2/P1 常规逐）：先折 P1/P2 存根、不足才折 P0
                          压到 0.75×cap 下 → 停；压不到 → 100% force_evict 兜底
```

> S1 落地口径：降档带为 90%（tier90，P0 逐出）→ 75%（tier75，P2/P1 逐）两档 + 100% force_evict 兜底。65% 分页档 / 55% 清垃圾档本 PRD 不做（§6 不落地）。80-90% 区间 P0 面零变化（owner 红线③：P0 只在 90% 档逐）。

**与现状的本质差别**：现状是"55% 一触发全链跑（80% 软逐 + push cap + §4.5 90% 段级）"、无分档、无估值 gate、无"压到目标下就停"。本 PRD 把 80% 软逐（P2/P1 逐到 0.75×cap）并入 75% 档、把 §4.5 90% 段级升级为 90% 纯容量逐出档（tier90）、新增每档估值 gate。

### 1.2 估值 gate（分母 = 当前用量 `w.used_tokens`，owner 裁定）

每档"压到目标水位下"前，先用**代码层确定性估值**（`_reclaim_est`，est_tokens 差值，零 LLM）估算该档动作能省多少；省量 < 阈值 → 不执行该档、pass 给下一档（省 LLM 面开销、避免无效 compact）。

| 档 | 估值分子（代码层怎么算） | 阈值 | 可确定性算？ |
|---|---|---|---|
| ① 90% 超压档（tier90） | Σ(被逐 P0 段 est_tokens(原文) − est_tokens(digest 摘录)) | 省 ≥ 0%×used（90% 档 no_gate，纯容量直接逐，不走估值 gate） | ✅ 确定性（est_tokens 纯函数） |
| ② 75% 软水线（tier75） | Σ(P1/P2 段 est_tokens(原文) − 存根) （不足才 + P0 段同上） | 省 ≥ 20%×used | ✅ 确定性 |

**分母口径（owner 拍）**：`w.used_tokens`（sc 窗口当前全段 resident+digest 摘录累加，`distill.py:60`）。75% 档阈值 20% 是"省量 / 当前用量"。

**90% 档 no_gate（关键设计）**：90% 超压是最高危险度档，纯容量逐出、不走估值 gate（`_tiers_by_water` 首行 `no_gate=True`）——压不到 0.9×cap 下就 pass 给 75% 档接住，不顶死。

### 1.3 "全 pass 不落地"风险（reviewer 面 1 钉死）

降档序每档"压不到 → pass 下一档"是**单调累积**（档 i 做完的折存根/退段保留到档 i+1，回收量单调不降）。若 75% 档也压不到 0.75×cap 下 ⇒ 窗口内已无可操作面 ⇒ 物理满（backpressure 正解，`result.status="backpressure"`，宿主 100% force_evict 兜底接）。**无死循环、无顶死**（降档序里危险第一手 = 最强手段 90% 纯容量逐）。
